# makeover-monday

Weekly Makeover Monday dashboards. One folder per ISO week (`2026W46`), each self-contained: `app.py`, `app.yaml`, `requirements.txt`, `static/`, `data/`.

Hosted on GitHub Pages: `https://ethanfeiza.github.io/makeover-monday/<week>/static/index.html` (frame it in a Tableau Public Web Page object).
